# ⚔️ Isekai Character Generator

Generate your fully realized Isekai RPG character — complete with AI portrait, stats, special skills, backstory, traits, and alignment. Powered by [Pollinations AI](https://pollinations.ai).

## Features

- 🎲 **Random Character Generation** — Race, Class, Stats, Skills, Appearance, Backstory
- 🎨 **AI Portrait** — Generated by Pollinations AI image API based on your character
- 🔗 **Shareable URL** — Every character is accessible via a unique seed-based URL (no login needed)
- 🌐 **Public Gallery** — Publish your character to a community gallery
- 📥 **JSON Export** — Export character data for use in game development
- ⚡ **BYOP** — Bring Your Own Pollen: users connect their own Pollinations account, zero hosting cost

## Live App

👉 [isekai-character-generator.pages.dev](https://isekai-character-generator.pages.dev)

## Powered By

- [Pollinations AI](https://pollinations.ai) — Image generation API
- Cloudflare Pages — Free static hosting
- Pure HTML/CSS/JS — No framework, no build step

## BYOP Integration

This app implements the [Bring Your Own Pollen](https://github.com/pollinations/pollinations/blob/main/BRING_YOUR_OWN_POLLEN.md) pattern. Users authorize with their own Pollinations account so image generation uses their own Pollen balance, not the app developer's.
